# Sri Ram Sharma — Developer Portfolio

The source code for my personal engineering portfolio, showcasing projects in artificial intelligence, backend infrastructure, systems engineering, and developer tooling. Built with a focus on high-performance static rendering, clean UI/UX, and automated CI/CD deployments.

🌐 **Live Website:** [sriramxdev.me](https://sriramxdev.me/)

---

## 🛠 Tech Stack & Architecture

### **Core Frameworks & Tools**
* **Framework:** [Astro](https://astro.build/) (Static Site Generation / High-performance architecture)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Responsive, glassmorphism design system)
* **Deployment & Hosting:** [Cloudflare Pages](https://pages.cloudflare.com/) (Edge network delivery with custom routing)
* **Version Control & CI/CD:** GitHub Actions linked with Cloudflare build triggers

### **Engineered Sub-Routing & Infrastructure**
* **Reverse Proxy / Subdomains:** Integrated custom Cloudflare DNS routing and GitHub Pages mapping for standalone project showcases (e.g., [`a-stride.sriramxdev.me`](https://a-stride.sriramxdev.me)).
* **SEO & Meta Engine:** Custom Open Graph (`og:image`, `og:title`) and search crawlers metadata configured for automated Google Search Console indexing and social link previews.
